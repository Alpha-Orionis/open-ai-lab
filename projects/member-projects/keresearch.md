# keresearch · 科研工作流 Skills

围绕选题、实验、论文写作与投稿流程整理的一组 Agent Skills。可以从项目规划、篇章结构和句子表达三个层次，为具体科研任务提供工作流参考。

**English:** A collection of research-workflow skills for project planning, experiment records and academic writing, with module-level attribution.

## 使用入口

先阅读源仓库的 [README](https://github.com/yunyancuo/keresearch/blob/c43943d03164973b275774867aa2e8f48891b936/README.md)，了解模块分工，再按所用宿主的 Skills 安装方式选择需要的目录。源 README 提供 ZCode / Claude Code 的目录安装示例；本次未安装或激活这些 Skills。

适合先选择一个边界明确的小任务，例如整理一份实验记录，或检查一段已有文章的结构。保留原始输入、使用模块、输出、人工修改和未解决问题，便于交流实际效果。涉及研究数据与文章内容时，使用本人有权处理的材料。

## 可讨论的协作方向

- 用小案例记录模块是否易于使用、不同宿主的目录安装是否一致。
- 将实验日志、来源引用与失败案例记录方式，对照社区的 [实验记录模板](../../templates/experiment-report.md) 提出改进。
- 梳理不同模块的职责与重叠，补充安装和归属说明；不以生成文本代替研究证据。

以上为协作建议，效果需要在具体任务中验证，不预设论文或投稿结果。
