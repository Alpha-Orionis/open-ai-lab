# 成员项目展示

这里收录成员已有的公开项目和学习资料，提供原仓库、作者主页、内容入口与可讨论的协作方向。欢迎从一个具体问题开始交流。

本目录提供项目介绍，代码与历史记录保留在原仓库。成员项目的展示状态与社区共创项目的立项、评测和验收状态分别记录。

| 项目 | 适合谁 | 可以从哪里开始 |
| --- | --- | --- |
| [VeloRAG · RAG 应用框架](velorag.md) | 关注检索、知识图谱、Agent 与应用工程的成员 | 阅读检索流程、补充最小运行说明、讨论检索与引用评测 |
| [keresearch · 科研工作流 Skills](keresearch.md) | 想梳理选题、实验记录与论文写作流程的成员 | 阅读模块分工，选择一个小任务尝试并记录反馈 |
| [深度学习基础笔记](deep-learning-notes.md) | 正在学习 PyTorch 与深度学习数学基础的成员 | 从线代、自动求导或线性回归 Notebook 开始阅读 |

## 作者与协作入口

以上项目由 [云烟错（yunyancuo）](https://github.com/yunyancuo) 提交介绍；keresearch 中引用与整理的上游模块另有作者与许可，详见对应页面。

- 项目使用与代码问题：在各自原仓库发起 Issue。
- 与社区任务的关联与后续协作：在 [项目收录任务 #5](https://github.com/Alpha-Orionis/student-ai-open-lab/issues/5) 讨论。
- 后续补充项目：写清原仓库、作者、当前状态、内容入口、验证记录和协作范围，再通过 PR 提交介绍。涉及新共创立项时，使用 [项目提案模板](../../templates/project-proposal.md)。

本批介绍于 2026-10-19 核对源仓库文件与版本；尚未在新环境运行应用、执行 Notebook 或评测 Skills 效果。各页面列出具体检查范围与待完善项。
