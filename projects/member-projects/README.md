# 成员项目展示

从一个能用的小工具开始，交流功能设计、实现方法与实际使用反馈。这里收录成员已有的应用作品，提供原仓库、预览或下载入口，以及作者个人主页。

本目录提供项目介绍，代码与版本历史保留在原仓库。成员项目的展示状态与社区共创项目的立项、评测和验收状态分别记录。

## 作者与协作入口

以上作品由 [云烟错（yunyancuo）](https://github.com/yunyancuo) 提交展示，每个项目页均保留作者主页与原仓库。

- 项目使用与代码问题：在各自原仓库发起 Issue。
- 社区内的协作建议：在 [项目收录任务 #5](https://github.com/Alpha-Orionis/student-ai-open-lab/issues/5) 讨论，例如 Windows 兼容性、交互体验、安装文档和插件测试。
- 后续补充项目：写清原仓库、作者、当前状态、内容入口、验证记录和协作范围，再通过 PR 提交介绍。涉及新共创立项时，使用 [项目提案模板](../../templates/project-proposal.md)。
