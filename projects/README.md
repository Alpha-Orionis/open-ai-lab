# 共创项目目录

社区共创项目目前只有提案，尚未提供应用实现。新增共创项目先填写 [项目提案模板](../templates/project-proposal.md)，通过 Issue 讨论范围、数据、维护与验收。

## 社区共创项目

| 项目 | 状态 | 科研任务 | 工程任务 |
| --- | --- | --- | --- |
| [校园知识助手](campus-knowledge-assistant/README.md) | 首个项目提案，待讨论 | 检索与引用评测、拒答与误差分析 | 数据处理、问答接口、前端与部署 |
| Paper Reproduction Lab · 论文复现 | 候选，未启动 | 基线复现、消融实验、Benchmark 与研究报告 | PyTorch、环境与实验管理、复现脚本 |
| Open Agent Workshop · Agent 共创 | 候选，未启动 | 规划、可靠性与工具调用评测 | API、工具集成、工作流与可复现测试环境 |

首期只推进校园知识助手，先使用小规模合法数据与低成本运行方案。后续在首个项目有可验证成果和新增维护能力后，再决定是否启动第二个项目。论文阅读助手、开源贡献助手和多模态功能可以作为未来提案讨论，暂不并行立项。

项目进入开发前，应有明确的维护者、最小交付范围与合法可用的数据。候选项目不代表已经启动或接受任务认领。

正式成果按 [项目成果标准](../docs/project-standards.md) 验收，首期任务和四周协作方式见 [启动方案](../docs/launch-plan.md)。
