# Career Track · 就业方向

把“做过项目”变成能够运行、解释、验证和展示的工程经历。

## 推荐任务

- 需求与产品：界定用户、使用场景、输入输出和不做的内容。
- 工程开发：接口、前端、数据流程、配置管理与错误处理。
- 质量保障：自动化测试、样例评测、引用与回答质量检查。
- 部署与运维：可复用部署步骤、日志、限流、费用预算与故障处理。
- 团队协作：任务拆解、PR 评审、迭代记录与版本说明。

## 最小交付包

1. 场景、需求、架构和关键技术选择。
2. 可运行代码、依赖及环境变量示例；示例只包含占位值。
3. 启动/部署步骤、测试或评测方式、已知限制。
4. 演示截图或视频，以及无需泄露密钥的复现方式。
5. 关联的 Issue、PR、评审记录与本人贡献说明。

部署优先支持本地复现；云服务或付费模型需提前说明预算与负责人，不默认要求贡献者自行付费。

## 作品集表达

按“问题—我的工作—验证证据—结果与限制”组织案例。涉及性能、准确率或成本改进时附测试条件和原始记录；没有证据时不写提升百分比。

实习准备可以围绕项目讲解、代码走读、技术复盘与模拟面试展开；参与社区不代表实习或就业保证。
