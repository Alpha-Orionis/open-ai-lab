# 开放成果规则

无限猴子实验室的原则是：开源所有有权公开的项目成果，让任何人都能学习、复现、修改与贡献。现阶段仓库主要是社区文档和项目提案；本规则也适用于后续新增成果，不代表已有应用或模型发布。

## 公开什么

| 内容 | 提交要求 |
| --- | --- |
| 原创代码、工具与应用 | 源代码、依赖版本、运行步骤、必要配置示例和测试说明；默认 MIT |
| 教程、文档与设计 | 可编辑源文件、引用来源与必要素材；默认 MIT |
| 实验与评测 | 脚本、配置、环境、数据版本、指标定义、可公开的原始与汇总结果、失败案例和局限；原创部分默认 MIT |
| 数据与样例 | 说明来源、许可、处理方式和版本；只提交有权公开再分发的部分，优先使用原创样例 |
| 模型与权重 | 原创成果在有权发布时提供权重、训练或处理说明与许可；第三方模型遵守其原许可，受限时仅提供获取与复现步骤 |
| 协作过程 | Issues、PR、技术决策、任务状态与复盘；同步交流后补充公开文字记录 |

## 许可与来源

除单独标注的第三方材料外，仓库原创内容沿用根目录 [MIT License](../LICENSE)，允许依许可使用、修改、分发和商业使用，并保留版权与许可声明。贡献者需有权发布自己的提交，不转移原作者署名。

第三方代码、数据、论文、模型和素材保留各自许可；在相关目录的 README 中列出来源、版本、许可及再分发限制，必要时附原许可文件。公开可访问不等于可以复制再分发；授权不明时提供链接、获取步骤或原创替代，不把第三方材料重新标为 MIT。

## 不能直接公开的内容

不提交密钥、令牌、个人隐私、私有课程或公司材料、保密信息以及无权再分发的内容。使用配置示例和原创或合成样例帮助复现。因授权或隐私不能公开某项输入时，说明缺失内容、原因、影响与替代步骤，不宣称完全可复现。

开源的应用若依赖付费 API、专有模型或外部服务，须明确费用、版本、获取条件和限制；尽可能提供开放模型、本地实现或不需要密钥的示例。不得将第三方依赖也描述为本社区已经开源的成果。

## 人人可以参与

没有学历、学生身份、职业或地区门槛，不收报名费，不要求先加入组织。可以提问、翻译、改文档、设计、整理有授权的数据、报告失败案例、开发和评审。

小改动可直接提交 PR；较大任务先公开讨论范围与评审支持。开放参与不自动授予主分支写权限，合并按公开标准评审。见 [贡献指南](../CONTRIBUTING.md) 和 [治理章程](../GOVERNANCE.md)。
