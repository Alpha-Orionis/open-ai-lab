# 招募与参与规则

状态：筹备期规则与招募文案草稿。目前未安排固定报名截止日期或活动时间，也未确认导师或核心成员名单。

## 我们希望与你一起完成什么

Student AI Open Lab 面向希望学习 AI、参与真实开源协作的大学生，以完成一个可运行、可评测、可展示的 AI 应用为首期共同目标。

你可以从文档、数据整理、示例和测试开始，也可以参与检索评测、论文复现、API、界面和部署。科研与就业成员围绕同一个项目协作，通过 PR、Review、实验与演示保留成长证据。

## 谁可以参与

- 欢迎不同高校、专业和基础的大学生，以中文协作为主。
- 不以学校排名、学历层次、是否零基础或付费能力筛选普通贡献者。
- 无需先加入 GitHub Organization，通过 Fork 和 PR 即可参与公开任务。
- 可以先阅读、提问和观察；维护者是否能接纳具体任务，以 Issue 中的协商为准。

普通贡献参与持续开放；核心团队意向以首批 3–5 人作为建议规模，不表示已有名额、已确认成员或录取承诺。

## 两种参与方式

| 方式 | 开始方式 | 期望与边界 |
| --- | --- | --- |
| 开放贡献 | 选择 `good first issue` 或 `help wanted` 任务，先说明计划 | 一次只接适合自己时间与基础的任务，交付后回应评审 |
| 核心协作意向 | 用任务提案 Issue 说明愿意承担的角色、相关能力或作品，以及可投入时间范围 | 先约定一次小范围协作，再共同确认职责；不自动授予仓库权限 |

初期优先补足 Project Lead、Maintainer 及文档/数据/评测协作。Mentor 可以提供工程或研究指导，但在确认人选前不对外承诺指导资源。

## 意向说明模板

在对应任务中简要说明即可；无需另建自我介绍文件：

```text
GitHub 昵称：
感兴趣的方向：Learning / Building / Research / Career
准备参与的任务或角色：
已有基础或公开作品（可选）：
可投入的时间范围与可能需要的帮助：
准备交付什么、如何验证：
```

不要求公开真实姓名、学校、学生证、手机号、身份证件或简历。需要进一步沟通时由双方自行确认渠道，仓库暂不收集报名表或私人联系人清单。

## 参与确认与成长

贡献者与维护者根据任务范围、投入时间、评审支持和资源条件确认协作。核心角色以实际贡献、沟通和可持续投入共同评估，不以关系、付费或单纯 PR 数量决定。阶段成果按 [成长路径](learning-path.md) 记录。

遇到课程或考试冲突可以暂停，及时记录任务进度与下一步，供他人接续；没有完成的任务如实标注。退出不抹除已有作者署名和贡献记录。

## 能获得的体验

- 能够运行和讲解的项目实践，以及有证据的个人贡献说明。
- 在维护者能力范围内安排的 PR Review 与同伴反馈。
- 可复现的研究任务、评测方法与失败案例分析。
- 项目演示、技术复盘和作品集表达练习。

这些是社区希望提供的协作方式，不保证固定评审时效、论文发表、录取、实习或就业结果。

## 发布招募前

维护者应确认首期任务范围、能提供的评审人力、时间安排、费用边界和反馈入口，再按实际情况对外发布。本文是仓库内的参与规则与文案草稿，不代表已经向其他平台发布招募消息。
